# Quantum Crypto Research

Исследовательский проект: **«Криптография в эпоху квантовых вычислений: угрозы, уязвимости и постквантовая защита»**.

## Цель

Экспериментально исследовать:
- влияние алгоритма Гровера на сложность перебора;
- различия между классическими и постквантовыми цифровыми подписями;
- размеры ключей и подписей;
- время генерации ключей, подписи и проверки;
- накладные расходы при использовании больших постквантовых подписей.

## Структура

- `experiments/grover/` — модель сложности поиска.
- `experiments/signatures/` — бенчмарк ECDSA и ML-DSA.
- `experiments/transaction/` — модель накладных расходов подписей.
- `data/` — сырые CSV-результаты.
- `results/figures/` — графики.
- `results/tables/` — подготовленные таблицы.
- `tests/` — автоматические проверки.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Для ML-DSA используется `liboqs-python`, официальный Python-wrapper проекта Open Quantum Safe. Он может автоматически собрать совместимую версию `liboqs`, если системная библиотека отсутствует.

## Запуск экспериментов

Модель Гровера:

```bash
python -m experiments.grover.grover_model
```

Сравнение ECDSA P-256 и ML-DSA-65:

```bash
python -m experiments.signatures.run_benchmark
```

Результат сохраняется в:

`data/signature_benchmark.csv`

Для каждой схемы фиксируются:
- время генерации ключей;
- время подписи;
- время проверки;
- размер открытого ключа;
- размер закрытого ключа;
- размер подписи.

## Принцип исследования

Код не должен заранее предполагать результат. Эксперимент получает измеряемые данные, сохраняет их, а выводы делаются после анализа результатов.
