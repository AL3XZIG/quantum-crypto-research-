# Quantum Crypto Research

Исследовательский прототип для работы **«Криптография в эпоху квантовых вычислений: угрозы, уязвимости и постквантовая защита»**.

## Что именно исследуется

Проект разделён на несколько воспроизводимых экспериментов:

1. **Grover model** — математическая модель перехода от классической сложности поиска N к идеализированной квантовой оценке √N.
2. **ECDSA vs ML-DSA** — реальное программное сравнение цифровых подписей: KeyGen, Sign, Verify, размер открытого ключа, размер закрытого ключа и размер подписи.
3. **Signature overhead** — оценка влияния увеличенного размера подписи на объём подписных данных.

Главный принцип проекта: **результаты статьи не должны задаваться вручную**. Таблицы и графики строятся из данных, полученных программой.

## Структура

- `experiments/grover/` — модель алгоритма Гровера.
- `experiments/signatures/` — бенчмарк ECDSA P-256 и ML-DSA-65.
- `experiments/transaction/` — модели накладных расходов.
- `experiments/run_all.py` — единая точка запуска.
- `data/` — сырые CSV-результаты.
- `results/figures/` — автоматически построенные графики.
- `results/tables/` — таблицы для дальнейшего анализа.
- `tests/` — автоматические проверки.

## Установка

~~~bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
~~~

Для ML-DSA требуется доступная в окружении реализация Open Quantum Safe через `liboqs-python`. Если ML-DSA-65 отсутствует в установленной сборке, бенчмарк завершится с явным сообщением об ошибке, а не подменит результат другим алгоритмом.

## Запуск

### Полный прототип

~~~bash
python -m experiments.run_all
~~~

Он последовательно создаёт:

- `data/grover_results.csv`;
- `data/signature_benchmark.csv`;
- `results/figures/signature_times.png`;
- `results/figures/signature_sizes.png`;
- `results/tables/signature_benchmark_summary.csv`.

### Отдельно: модель Гровера

~~~bash
python -m experiments.grover.grover_model
~~~

### Отдельно: цифровые подписи

~~~bash
python -m experiments.signatures.run_benchmark --repetitions 100
~~~

### Анализ результатов

~~~bash
python -m experiments.signatures.analyze_results
~~~

## Методика бенчмарка

Для каждой операции выполняется серия измерений. Перед серией используются несколько прогревочных запусков, которые не входят в итоговую статистику. В CSV сохраняется среднее время выполнения.

Размеры ключей и подписей измеряются непосредственно у объектов, созданных реализацией. Для ECDSA используются DER-представления ключей; это важно учитывать при интерпретации результатов: размер здесь относится к выбранному формату сериализации, а не только к математическому размеру кривой.

Для ML-DSA фиксируется конкретный вариант **ML-DSA-65**. Подпись сначала проверяется, чтобы эксперимент не мог незаметно сохранить результат неработающей реализации.

## Что не утверждает этот прототип

- Он **не симулирует физический квантовый компьютер**.
- Модель Grover показывает асимптотическое соотношение и не является оценкой реальной производительности квантового процессора.
- Бенчмарк измеряет конкретные программные реализации и конкретное аппаратное окружение.
- Время выполнения нельзя переносить на все компьютеры без повторения эксперимента.
